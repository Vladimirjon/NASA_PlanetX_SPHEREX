# NASA Space Apps 2026 · Planet X and SPHEREx · Equipo Na za

Herramienta web pública que muestra, como un blink, imágenes reales de SPHEREx de cualquier región del cielo (RA/Dec), comparadas a la misma longitud de onda. Nombre de la app: pendiente.

## Para el equipo: por dónde empezar

1. [docs/ROLES.md](docs/ROLES.md): los cinco roles, los contratos entre ellos, el horario y los pasos exactos de cada rol.
2. [docs/problema.md](docs/problema.md): el enunciado del reto.
3. [PRODUCT.md](PRODUCT.md): usuarios, propósito, stack y principios.
