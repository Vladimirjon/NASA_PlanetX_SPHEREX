# Índice HiPS SPHEREx — plan de implementación

**Objetivo:** generar de manera reproducible la geometría de las 12.288 celdas HEALPix del mosaico DR1, con trazabilidad a IRSA.
**Alcance:** utilidad offline para el equipo; no es un visor, una API ni un índice temporal. Ficha `docs/specs/0001-exploracion-cache-borrador.md`, aprobada por Dax el 14-nov-2026 como base de exploración y caché; detalles científicos y módulos posteriores requieren sus propias fichas.

1. Fijar instantánea de propiedades IRSA, versión y huella; comprobar sus parámetros antes de usarlos.
2. Escribir pruebas: cobertura/identificadores, ejemplo de IRSA, longitud de onda, integridad, reproducción, rechazo de metadatos alterados y directorio existente.
3. Generar centros y cuatro vértices de celdas en grados ICRS, URLs y manifiesto con hash; los bordes reales no son necesariamente segmentos rectos.
4. Verificar con Astropy y hpgeom, ejecutar tests/lint, examinar el resultado y documentar ejecución y límites; no descargar masivamente ni presentar mosaicos como épocas.
